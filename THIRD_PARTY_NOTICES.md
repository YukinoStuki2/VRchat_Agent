# Third-Party Notices

## UnityAgent

This package adapts read-only diagnostic ideas and selected algorithms from:

- Project: `AjisaiFlow/lighfu unity-agent`
- Repository: https://github.com/lighfu/unity-agent
- Audited commit: `347f054a0c934c3ee14b0568968cd269726de323`
- License: MIT
- Copyright: AjisaiFlow / lighfu contributors

Adapted areas include avatar body/face renderer heuristics, expression-parameter
usage analysis, Write Defaults inspection, performance counting, hierarchy and
component inspection, and outfit-to-avatar bone compatibility analysis.

The original UnityAgent dispatcher, model providers, credentials, write tools,
build/upload tools, arbitrary script execution, and XML tool protocol are not
included.
