## 0.2.0-preview.5 · Unity 面板：连接、权限、任务

- 保留原菜单 **Tools → VRChat Agent → 候选权限与清单**。默认先看连接状态，选择 Hermes 或本机 Codex，再明确启动。高级连接参数默认收起。
- 「权限」列出常用读取及可搜索的原生操作目录；「任务」显示需要核对的读取请求，并按材质、单文件、截图分类。停止连接和撤权保持可见。
- 本次只改 Unity 编辑器窗口，不改变任务批准、图片发送确认、备份、连接协议或依赖版本。切换页面和展开说明都不会连接或授权。旧版本保留在同一 VCC 源。
- 未在用户 Windows 编辑器上检查实际显示效果。
